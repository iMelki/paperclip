# Forbidden tokens - tracked, non-secret structural patterns.
#
# One literal token per line. Blank lines and lines starting with "#" are ignored.
# Tokens are matched as FIXED STRINGS (git grep -inF), case-insensitively, against
# every tracked file except pnpm-lock.yaml and this file itself.
#
# WHICH LIST DO I ADD TO?
#   * A real person's name, a host name, an account name, or anything else whose
#     value is itself the secret  ->  NOT here. Put it in the private, untracked
#     per-machine list at <git-common-dir>/hooks/forbidden-tokens.txt. Writing such a
#     value into this tracked file would publish the exact string the check exists to
#     keep out of the repository.
#   * A non-secret structural pattern every checkout should share  ->  here.
#
# THIS LIST IS INTENTIONALLY EMPTY OF ACTIVE PATTERNS.
